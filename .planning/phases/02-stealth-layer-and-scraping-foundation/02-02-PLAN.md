# Plan 02-02: patchright Migration + Context Reuse + Rate Limiting

## Objective
Replace playwright-stealth with patchright in scraper.py, implement browser context reuse across URL batches, and add the _human_delay() rate limiting method that reads config from Target_Specs.json. Activate the corresponding test stubs.

## Context
The existing `career_agent/src/scraper.py` uses `from playwright.async_api import async_playwright` and calls `stealth_async(page)` per page. It also creates a new browser+context per method call (search_linkedin_jobs and get_linkedin_job_description each launch their own browser). This plan migrates to patchright (identical API, CDP-level stealth), removes the stealth call, refactors to reuse browser context across a batch, and adds configurable delays.
