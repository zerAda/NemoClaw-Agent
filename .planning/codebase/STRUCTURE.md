## Naming Conventions

**Files:**

- **Python modules:** lowercase_with_underscores (e.g., `app.py`, `client_factory.py`, `scraper.py`)
- **Configuration files:** UPPERCASE or descriptive lowercase (e.g., `Target_Specs.json`, `Bio_Context.md`, `selectors.yaml`)
- **Markdown docs:** UPPERCASE (e.g., `agent.md`, `CLAUDE.md`, `README.md`)
- **Docker compose:** `docker-compose.yml` (root-level; no versioning suffix)
- **GitHub workflows:** kebab-case with descriptive prefix (e.g., `nemoclaw-ci.yml`, `nemoclaw-cd.yml`)

**Directories:**

- **Root-level components:** Descriptive lowercase (e.g., `career_agent/`, `brain/`)
- **Package structure:** Follows Python convention (e.g., `src/`, `config/`)
- **GSD outputs:** All caps (e.g., `.planning/codebase/ARCHITECTURE.md`, `.planning/codebase/STRUCTURE.md`)

## Special Directories

**`qdrant_db/`:**
- Purpose: Local vector database for job deduplication and tracking
- Generated: Yes (auto-created by MemoryService on first run)
- Committed: No (.gitignore'd)
- Location: `./qdrant_db` (relative to working directory when running Career Agent)

**`brain/applications/`:**
- Purpose: Generated cover letters and application artifacts
- Generated: Yes (auto-created as UUID-named subdirectories by PhoenixApp)
- Committed: No (application artifacts are runtime-generated)
- Structure: `brain/applications/{uuid}/cover_letter.txt`

**`.venv/`:**
- Purpose: Python virtual environment with pip dependencies
- Generated: Yes (created via `python -m venv .venv`)
- Committed: No (.gitignore'd)
- Contents: Installed packages (playwright, pydantic, qdrant-client, openai, etc.)

**`.env` (and `.env.*` files):**
- Purpose: Runtime secrets and configuration
- Generated: Manually (copy `.env.example` and populate) or via CD pipeline
- Committed: No (.gitignore'd; security risk)
- Contents: GEMINI_API_KEY, TELEGRAM_BOT_TOKEN, NEMO_AUTH_USER_ID, NEMO_PAIRING_CODE
